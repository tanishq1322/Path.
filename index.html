Firebase setup instructions
  1. Create a Firebase project with help from a parent/guardian if needed.
  2. Add a Web App and copy its API key, Auth domain, Project ID and App ID here.
  3. Enable Authentication → Google sign-in.
  4. Create a Firestore database and publish the PATH Firestore rules supplied with this download. The rules ensure each account can access only its own journal.
  5. Add your website domain under Authentication → Settings → Authorized domains. The website must be hosted on HTTPS; opening the HTML directly as a file will not support Google sign-in.
